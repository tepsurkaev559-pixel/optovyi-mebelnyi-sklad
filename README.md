# Оптовый мебельный склад

Готовый сайт-каталог для Netlify. Покупатели смотрят товары без регистрации. Администратор входит через Netlify Identity; серверная функция проверяет роль `admin`. Каталог и фото сохраняются в Netlify Blobs.

## Перед публикацией
1. Подключите этот GitHub-репозиторий к существующему проекту Netlify `celebrated-yeot-bb6d95`, чтобы сохранить прежнюю ссылку.
2. Оставьте Netlify Identity включённым и регистрацию Invite only.
3. Убедитесь, что вашей учётной записи Netlify Identity назначена роль `admin`.
4. Netlify установит зависимости из package.json и развернёт функции.
5. Проверьте публичный просмотр без входа и добавление товара из панели владельца.

## Возможности первой версии
- Четыре категории: Диваны, Столы и стулья, Кровати, Шкафы.
- Поля товара: категория, название, описание, фотографии с телефона.
- Фото хранятся отдельно в Netlify Blobs; карточка показывает изображение без чрезмерного увеличения.
- После «Сохранить товар» запись сразу сохраняется в облаке, новый deploy для каждого товара не нужен.
- До 8 фотографий на товар; до 8 МБ на фото; суммарно до 15 МБ через форму.

В этой версии добавление товаров реализовано; редактирование/удаление и создание новых категорий пока не включены. Не добавляйте пароли и токены в код и не отправляйте их в чат.
